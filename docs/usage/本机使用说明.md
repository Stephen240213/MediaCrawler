# MediaCrawler 本机使用

> 本文命令及行内文件路径均以项目根目录为基准。

双击项目目录中的 **MediaCrawler Local.command**，浏览器将打开 http://127.0.0.1:8080 。启动窗口需保持打开，按 Control+C 停止服务。

界面支持中文、平台与关键词配置、二维码登录、任务启停、实时日志、数据预览和导出。首次使用请阅读界面许可说明，再完成环境检测。

默认使用独立 Chrome 配置目录自动启动浏览器，无需修改日常 Chrome 的远程调试设置。首次采集时，在弹出的浏览器中自行扫码并完成平台验证，后续登录态保存在 `browser_data/`。

采集结果位于项目的 `data/`。默认保存为 JSON，不需要另装数据库。可在界面选择 JSON、CSV、Excel 或 SQLite。

首次实际采集需要你选择平台和关键词并登录。环境检测通过仅表示程序依赖可运行，不代表平台登录或采集已经成功。

GitHub Actions 对 NanmiCoder/MediaCrawler 的更新监测按本次要求暂缓配置。

## 部署记录

Python 3.11 与 uv 安装在本项目目录，未替换系统 Python。前端已构建到 `api/webui/`，由后端统一提供。服务仅监听 `127.0.0.1:8080`。Node.js 使用 Codex 随附的本机运行时。

`uv.lock` 保留上游的依赖版本与 SHA256 校验值，仅将包文件下载地址从清华镜像改为官方 `files.pythonhosted.org`。

启动脚本设置 `UV_NO_SYNC=true`，直接使用已安装且通过兼容性检查的锁定依赖，避免每次启动重新联网解析。首次字体缓存已在 `.cache/matplotlib/` 初始化。

部署验证：前端构建成功；环境检测、健康检查、配置、任务状态、数据列表及 WebSocket 状态均通过；`tests/test_api_limits.py` 共 12 项通过。尚未进行需要平台登录的真实采集。
