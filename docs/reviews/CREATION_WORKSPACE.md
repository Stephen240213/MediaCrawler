# 采集、分析与创作工作流

采集方式默认选择 RedFox MCP，浏览器采集仍可手动切换。工具目录按所选方式更新。RedFox 的榜单周期、搜索类型、排序、分类和语言等参数提供选择项；可选项默认不传给服务。部分取值仅为文档示例，提供“其他”输入服务支持的值，避免把示例误当成完整枚举。日期和时间使用对应控件，榜单日期沿用现有窗口校验。

小红书搜索排序按 [RedFox 文档](https://redfox.hk/apis/xiaohongshu/384C6W6B) 使用 `_0`、`_2`、`_4`；抖音账号搜索参考 [官方参数文档](https://redfox.hk/apis/douyin/P5CHB3BZ)。YouTube 热门评论 `top` 来自 [官方 SDK 示例](https://github.com/redfox-data/redfox-python-sdk)。未确认的值保留服务默认和自定义入口。

创作工作台分为“AI 辅助创作”和“草稿编辑与预览”。AI 创作按以下步骤执行：

1. 选择自己填写的材料、已完成的分析报告、账号/专题研究版本，或数据分析结果。分析报告和研究页面可直接带入；数据分析页面按当前筛选带入。
2. 选择内置内容创作 Agent 或视频脚本 Agent，并选用需求解答、决策对比、经历叙事、信息整理 Skill。创作需求折叠展示，按需设置受众、语气、平台等。
3. 确认模型调用后提交后台队列。结果可查看完整报告，或选用一个版本进入草稿编辑。重复选用不会覆盖已编辑的正式草稿。

这些 Agent 运行在工作台现有模型任务队列中，Skill 是工作台内置、带版本的创作方法。Agent 和 Skill 的内容冻结到任务来源，并实际进入模型提示与缓存指纹。它们没有调用桌面 Codex 的任意插件或本机工具的能力。视频 Agent 校验输出包含开头口播和分段脚本。

报告、研究与数据来源均由后端解析。任务保存来源编号、研究版本或数据筛选及生成时间。数据统计在提交时重新计算并冻结；正文、原文摘录及报告材料最多取前 18000 字，实际纳入范围在报告证据覆盖中记录。模型报告中的解释保留为推断；用户材料标记为用户提供。

AI 内容分析页分为“新建分析”和“分析结果”。结果页支持按名称查找和按任务状态筛选；账号/专题研究从已保存范围入口打开。单条分析提交后直接进入结果页。模型配置说明折叠，采集登录提示仅在采集与任务页显示。

本次按照用户最新要求在本机开发和验证。浏览器测试通过 `MEDIACRAWLER_TEST_BROWSER` 使用本机 Chrome，后端、媒体和模型均使用隔离夹具。未进行真实采集、账号登录、付费模型调用或发布。
