# 封面、卡片、字幕与人工发布包

> 本文命令及行内文件路径均以项目根目录为基准。

本轮由用户确认上一轮验收后实施，按已有授权直接在本地调整。沿用现有分析、成稿版本、账号画像、经验及发布结果回填；本轮不调用真实模型、平台采集或发布接口，也不增加依赖或下载模型。

## 操作路径

1. 刷新工作台，打开「AI 内容分析」中的已完成报告；在完整改写稿中编辑并保存成稿版本。
2. 在「封面、卡片、字幕与人工发布包」选择制作来源成稿，点击「从成稿生成制作草案」。会替换当前尚未保存的制作编辑，不覆盖历史制作版本。
3. 编辑封面及卡片，选择风格和画幅。可先保存未审核版本检查实际PNG预览；继续编辑后会另存新版本。
4. 按需要校对原视频字幕，或填写自有成片的真实时间轴。无视频时可直接制作图文包。
5. 核对文稿、事实、素材权利，以及所用字幕，勾选并保存新的制作版本。任意修改会清除当前核对标记。
6. 下载人工发布包，按说明到平台官方客户端手动上传。平台确认发布成功后，在既有「发布结果与同类复盘」登记实际成稿版本、账号、链接及时间，后续手工回填效果数据。

## 封面与卡片

- 本机模板排版：纸感绿、海岸蓝、深色金；三个画幅为1080×1440（3:4）、1080×1080（1:1）、1080×1920（9:16）。
- 封面和卡片均可编辑标题、正文、栏目、页脚。每份制作包含一张封面和最多8张可增删、调序的内容卡片。
- 草案从保存的成稿正文按顺序拆分；超过8页容量时明确提示，完整正文仍在包内，需人工选择卡片重点。该拆分不是额外的AI归纳。
- 自动换行并在安全区域内调整字号，超出最小字号后拒绝生成，提示精简或拆页，不静默截断文字。标题会尽量平衡多行长度。
- 已保存PNG可预览、单张下载；SHA-256及字节数可查看。模板图不包含AI插画、原笔记图片抓取或自定义照片背景。
- 使用系统中文字体。Mac优先使用STHeiti或PingFang；Linux支持Noto CJK或文泉驿。可在本机环境设置 `MC_REMIX_DESIGN_FONT` 指定字体文件；不会自动安装或下载字体。字体文件不会进入发布包，只记录名称与摘要。

验收：测试三个画幅、不同风格、长标题、换行、卡片增删调序、溢出提示；核对PNG真实像素与中文显示。页面显示的是所选已保存版本，未保存编辑有明确提示。

## 字幕

- 加载的是任务保存的完整 `transcript`，而非可能被证据预算截断的引用列表。不重新转写或调用模型。
- 原视频字幕使用真实原片时长，可校对文字和时间；原片可用时支持浏览器字幕轨道预览。
- 改写后重新录制的视频不能套用原片时间；选择手工时间轴并填写对应成片实际时长和每段时间。每页20段，最多1500段、15分钟，支持增加、删除和编辑。
- 校验毫秒精度下开始/结束、排序、重叠、总时长、有限数值与字幕块分隔符。每段最多两行，避免损坏SRT/VTT结构。
- UTF-8导出SRT/VTT，名称区分 `original-video` 和 `manual-video`。未启用字幕的版本不包含字幕文件。
- 本轮提供字幕文件和原片浏览器预览，不烧录硬字幕、不生成新口播、不合成成片；发布包不含原视频。

验收：核对完整字幕载入、修改、分页、非法时间与重叠拦截、SRT/VTT毫秒和中文内容；在对应视频中人工核对音画。原片字幕文件只能用于原片。

## 版本与交付

- 每次保存生成不可变制作版本，冻结来源成稿、设计参数、字幕、核对标记、字体及渲染器版本；后续更改成稿不会暗中替换旧PNG或字幕。可载入历史版继续编辑并另存。
- 确定请求键用于重试去重，内容不同的同键请求拒绝。每个分析任务最多保存100份制作版本。
- ZIP包含 `title.txt`、`body.txt`、`tags.txt`、`cover.png`、按序卡片、所选字幕、`design.json`、`manifest.json` 和 `README.txt`。
- 清单记录任务/成稿/制作ID、输入摘要、产物SHA-256、人工核对状态及 `published=false`。发布包不含原视频、字体文件、Cookies、模型配置或原始评论库。
- 导出前校验已存文件摘要、字节数及路径；文件缺失、损坏或符号链接均不静默交付。需要人工核对后保存的版本才可导出ZIP。
- 导出不创建发布记录，也不标记发布成功；仍需去官方页面人工发布并回填。

## 存储、兼容和检查

制作索引新增在本机 `.runtime/content-remix/analysis.sqlite3` 的 `production_revisions` 表；成品在 `.runtime/content-remix/production/<制作ID>/`，临时目录生成成功后原子移入。保存不覆盖旧版本。运行文件不入Git；更新前备份数据库。

复用现有JWT、角色、CSRF和审计边界。测试采用隔离数据库、模拟模型与本地fixture服务，本机Chrome执行桌面及移动端验证；本轮不代表云端部署或真实平台发布验收。
