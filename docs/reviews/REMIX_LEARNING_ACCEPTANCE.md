# 已确认：账号画像、评论议题和发布复盘

> 本文命令及行内文件路径均以项目根目录为基准。

本轮仅实现以下三部分。用户已于2026年10月26日确认验收，后续封面、卡片、字幕制作和人工发布包见 [制作验收清单](REMIX_MEDIA_ACCEPTANCE.md)；不自动发布、不自动采集效果数据、不自动训练模型。原有文案中的封面/镜头建议继续保留。

## 账号画像与经验作用域

- 创建画像，填写平台、定位、受众、语气、题材、禁用表达和内容原则；支持编辑、停用及版本历史。
- 选择画像会填入单次需求默认值，单次需求可继续修改。每个新任务冻结画像与实际使用经验的版本；更新画像不改变旧任务。
- 默认只检索当前画像的经验；通用经验需主动勾选。本轮之前的经验视作通用经验，不会自动归属任何账号。账号作用域之外仍按平台与题材匹配。
- 保存人工改写反馈时，经验默认归入报告当时使用的画像；经验库可显式选择作用域。项目内操作员共享管理权限，画像作用域是内容使用范围，不是新增的多租户权限隔离。

验收：建立不同画像，分别保存具有明显不同语气的经验；切换画像并检查作用域。在新报告“分析范围”检查所用画像和经验版本。涉及真实模型的新分析仍由用户确认提交，可能产生模型费用。

## 评论议题表

- 对已经纳入证据的去重评论做关键词多标签归类，展示费用与支付、门槛、位置配套、体验质量、操作、获取、风险等议题及未分类反馈。
- 计数由代码完成；一条评论可进入多个议题，分类计数不能直接相加。不是情绪识别，也不能视为全体观众意见或满意度。
- 每组提供代表引用、全部引用、应核对的信息和改写动作。仅代表本次实际纳入的样本，不包含未读取的评论。
- 新报告保存规则版本与议题快照。旧报告可按当前规则展示已有评论引用，并明确标记为历史重新整理，不触发模型调用。

验收：打开已有含评论的报告，点击议题引用，核对原文和样本数；检查无评论任务的空态。

## 发布结果回填

- 先保存实际发布的成稿版本，再填写对应平台公开链接、实际发布时间、实际发布账号、题材、内容形式及备注。允许同一分析任务登记不同已发布作品，不调用发布接口。
- 历史分析未绑定画像时，可以在回填中选择实际发布账号，不必为登记结果重新调用模型。该选择只属于发布记录，不改写历史分析画像。
- 链接保留公开地址、去掉查询与片段参数，不采集网页。重复的规范化链接不能跨任务重复计入样本。
- 每次观测单独保存时间、阅读/播放、点赞、收藏、评论、分享、有效咨询、转化及推广状态。推广状态分为未知、确认无推广、有推广；未知不作同类对照。空白为未知，0为已知零值；数据为人工回填，未经平台独立核验。
- 重复提交同一请求键不会产生重复快照。修正同一时点的数据可重新填写并提交新快照；同一观察年龄距离相等时优先使用较新的记录。
- 已有观测后禁止改动作品、所用版本、发布时间、账号和分组，避免悄悄改变统计口径；仍可修改备注。不同作品使用新的发布记录。

验收：用真实已发布作品回填，不将测试内容当作真实生产效果。核对保存的成稿版本、账号、链接、时间、未知与零值、观测历史和编辑冲突提示。暂无真实发布时可先检查表单及空态，自动化 fixture 已覆盖完整流程。

## 同类样本复盘

- 必须明确账号与题材；未归属记录不推断为同一个账号。
- 按同画像、平台、题材、图文/视频形式、推广状态和发布日相差不超过30天筛选；选择距指定发布后年龄最近、且落在允许误差内的观测。
- 默认观察年龄72小时、误差±24小时，可调整。不是把所有作品的最新累计值放在一起比较。
- 显示目标值、对照样本数、中位数、相对差异、框架分组及全部对照/反例；列出作用域、时间、推广和指标缺失的排除数。
- 对照不含目标本篇；未知指标不填0，真实0参与计算；基线中位数为0时不计算相对变化。没有或为0的阅读分母不计算收藏/阅读、咨询/阅读、转化/阅读的比值。这些比值不是爆款概率。
- 少于5篇会提示样本不足；即使更多也只描述观察差异，不声称框架或改写造成了效果变化。
- “整理为候选经验”只生成可编辑文本；必须再次人工确认才入经验库，保留账号、题材、来源任务和成稿版本。不会自动把一次高表现认定为通用规律。

验收：选择有同类对照的作品，切换指标、观察小时和误差；核对排除项、0值、未知值、样本不足提示、框架分组与反例。核对候选经验后再确认入库。

## 实现与验证

数据保存在本机 `.runtime/content-remix/analysis.sqlite3` 的独立表中，沿用现有角色、CSRF和审计边界。上线前备份数据库；旧任务和经验通过默认值兼容，不覆盖历史报告。运行目录、数据、配置和模型不提交到 Git。

自动化测试使用隔离SQLite、HTTP与模型fixture，不触发真实模型、登录、采集或发布。浏览器用本机Chrome执行桌面/移动布局和完整交互验证；这不是云端配置验收，也不是平台真实性能评测。

本轮本地验证：专项与权限回归121项、`scripts/cloud-check.sh` 工作台回归64项及前端生产构建、完整浏览器流程1项全部通过。更新前SQLite备份完整性通过；更新后健康检查、新表和历史报告接口正常，既有51条评论的报告可直接显示7个议题组，无需重新调用模型。尚无真实发布回填样本，真实效果复盘等待用户验收后积累数据。
