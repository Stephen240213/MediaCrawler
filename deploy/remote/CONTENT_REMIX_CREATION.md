# 内容分析、评论与改写

ContentRemixAgent 第一阶段支持标题、正文、语音、已有评论样本分析，以及按创作需求生成完整改写稿。分析使用私有 remote.env 中配置的模型服务；语音可使用本机 MOSS。不会自动采集、发布或训练模型。

## 使用流程

1. 选择已采集内容或上传视频，填写平台、输出形式、受众、目的、题材标签、语气、必须保留的信息和禁用表达。
2. 选择自动推荐或指定需求解答、决策对比、真实经历、信息筛选四类框架。补充资料会标记为用户提供，不能替代独立核实。
3. 选择是否纳入已有评论；上传素材也可以按每行一条的方式补充评论。评论仅来自本机 SQLite 数据或本次手动输入，不触发采集。分析页面会显示本机已保存评论数。
4. 确认文字、所选评论、需求与适用经验将发送给已配置的分析模型，再提交。云端 ASR 另会发送音频；本机 ASR 不发送音频。
5. 检查报告中的分析范围、评论引用、框架理由、完整正文、三个标题选项、视觉建议、修改说明和待核实事项。视频输出还包含开头口播和分段脚本。
6. 编辑标题和正文，填写修改反馈，保存多个成稿版本。选择“采用并保存到草稿”标记当前采用稿；每个版本有独立草稿，重复采用不会覆盖草稿中的人工编辑。
7. 点击“确认修改经验”才将反馈存入经验库。经验库支持个人偏好、修改经验和用户确认的规则，可编辑、停用、删除及查看版本历史。系统不自动把单次修改升级为通用规则。

历史报告保持原样；在当前需求区设置新要求、重新确认同意后，可点击报告中的“按当前需求重新分析此素材”。这会新建任务，重新读取已有资料，不覆盖旧报告；可能产生新模型调用费用。

## 证据和评论范围

- 新版输入包含原平台、作者、发布时间、采集时间以及已保存的互动计数。未知值保留 null，零值保留 0；上传素材不冒充已知发布平台。
- 评论从指定内容的已保存记录按发布时间倒序读取至多160条候选；去重后至多80条，每条最多500字，总计最多8000字。手动补充评论优先纳入，使用相同的去重与预算处理。
- 总证据上限30000字。需求、适用经验、正文、评论和语音共享预算；报告“本次分析范围”显示实际纳入字符和评论数。长正文或语音可能只纳入部分内容。评论样本不能等同全部观众，平台评论计数不等于已采集评论数。
- 评论结论必须引用评论证据。评论者的说法不能作为已核实事实；不使用样本推断整体人口画像、传播因果或爆款概率。封面文案和镜头建议是生成方案，本阶段尚未分析实际画面。
- 模型输出上限10000 token。不同服务仍需支持 /chat/completions 和 JSON 对象输出，输出结构与引用通过后端校验后保存。提示词和输入变化会生成不同缓存键。

## 经验复用与存储

经验限定于同一目标平台或全部平台；题材为空表示通用，非空时只匹配相同题材标签。具体平台和题材优先，每次最多六条，每条最多800字。经验的标题、版本和实际使用内容作为本次证据快照保存，修改或删除经验不会改变历史任务。

经验库、成稿版本、来源快照和报告均保存在本机 content-remix/analysis.sqlite3 中，沿用 .runtime 的私有目录。不得上传或提交到 Git。经验服务沿用工作台的操作员、CSRF 和请求审计边界；修改经验采用版本号检查，避免覆盖并发编辑。

本阶段记录人工偏好与修改反馈；发布结果回填、同类样本效果比较和自动复盘仍属于后续阶段。
